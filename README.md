# krita-chromatic-aberration
Chromatic Aberration python plugin for krita
Note: Not compatible with Krita 6 yet, written for Krita 5.3.3

![orpheus](https://cdn.hackclub.com/01a0a0ad-4c54-7617-9350-712f88a16769/orpheus.jpg)

^ image aberrated with the plugin :)


## Usage

1. Download package
2. In Krita Tools > Scripts > Import Python Plugin from File, select zipped package
3. Ensure plugin is enabled in Configure Krita > Python Plugin Manager
4. Restart Krita

Use by going to Tools > Scripts > Chromatic Aberration
See more settings by going to Configure Krita > Python Plugin Manager and selecting the plugin for the description
